# Didact Console

Didact Console is a companion web dashboard app - separate from Didact UI - for **customers only** who have purchased the paid plan enhancements. Didact Console offers a convenient customer portal where customers can manage license keys, users and teams, and more.

::: tip
See the [Didact Console overview](/core-concepts/didact-console/console-overview) for more details.
:::
